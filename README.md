# GRB-AI Navigator: Smart Gender Budgeting & Data Assistant

Prototype Streamlit app for Gender Responsive Budgeting (GRB) with intersectionality-aware analytics.

## Features

- Gender Data Dashboard (interactive charts + intersectionality filters)
- Budget Analyzer (analyze uploaded/sample budgets with GRB signals)
- AI Recommendation Engine (explainable, rule-based recommendations)
- Simulated Gender Data Lab (normalizes fragmented datasets into a single schema)

## Tech Stack

- Python
- Streamlit
- Pandas / NumPy

## Run locally

```powershell
pip install -r requirements.txt
streamlit run app.py
```

## Data

The app uses sample datasets in `data/` (generated by `src/sample_data.py`) if they are missing.
